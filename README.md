# Dockerized Web Infrastructure (Nginx & MySQL)

A multi-tier containerized web infrastructure project developed for Ausbildung documentation and portfolio purposes[span_0](start_span)[span_0](end_span).

## 🚀 Project Overview
This project sets up a local web environment using Docker and Docker Compose[span_1](start_span)[span_1](end_span). It integrates a high-performance **Nginx** web server with a **MySQL** database container, demonstrating containerization, service orchestration, and multi-tier network configuration.

## 🛠️ Technologies Used
* **Docker & Docker Compose** - For containerization and multi-container orchestration.
* **Nginx** - As the web server.
* **MySQL** - As the relational database management system.
* **HTML/CSS** - For the frontend web interface.
